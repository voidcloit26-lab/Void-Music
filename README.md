# VOID Music

**Your music. Your space.** An independently maintained Android music player based on the GPL-3.0 Mochy Music project.

- Maintainer: [VOID · Owner](https://discord.com/users/1472442073108971575)
- Community and support: [MARS Community](https://discord.gg/marscm)
- Android package: `online.voidbot.music`

## Development

This branch is a test build. The existing playback engine, library and audio processing are retained. Track availability depends on the selected provider and applicable rights and terms.

Build with Android Studio, JDK 21 and the checked-in Gradle wrapper. See the project build configuration and [release checklist](VOID_MUSIC_RELEASE_CHECKLIST.md) for details. Install only a verified APK from an authorized distribution channel. Automatic app updates and GitHub-based module release lookup are disabled in the independent build.
