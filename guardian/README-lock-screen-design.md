# Guardian lock screen design
Native Compose, existing app typography and palette, original VOID launcher mark, subtle violet radial glow, animated waveform and halo, entrance and verified-access transition. Motion is drawn without re-layout on every frame. The activation screen never initializes music playback or media services. It retains the device proof, receipt validation, existing access restore, pre-activation legal notice and owner access. Input is memory-only, screenshots disabled, provider errors sanitized, concurrent requests blocked, and the signed entitlement is rechecked before opening music. Compile and test on a real device, including reduced-motion settings, small screens, keyboard, offline retry and valid/invalid invitation. No player or backend changes.
