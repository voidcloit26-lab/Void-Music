# Owner-controlled signing procedure
Generate a new key only if there is no established VOID Music release signing identity. Run scripts/void-release-key.sh on a trusted computer, outside the repository and cloud CI. Keep the PKCS12 and unique password in owner-controlled encrypted storage. The public certificate SHA256 is safe to share. For a local release build, copy the keystore to the ignored app/keystore/release.keystore path in an isolated checkout, set STORE_PASSWORD, KEY_ALIAS and KEY_PASSWORD using a private shell prompt, and delete temporary credentials afterward. Use an independently verified Guardian HTTPS origin and public signing pin. Never distribute the debug signer, unsigned preflight, or a proprietary SDK build without authorization. Verify apksigner certificate SHA256 matches the recorded certificate, exact package name, R8 mapping and runtime security gates. No production credentials are generated in CI or committed here.
