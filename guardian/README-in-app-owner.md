# In-app Guardian owner access (staging)
Use Owner access on the locked screen or Settings > App behaviour > Legal > Guardian owner access. The non-exported activity embeds only the dedicated first-party HTTPS owner service. JavaScript, file/content access, mixed content, third-party cookies, external navigation, autofill and screenshot capture are disabled. No password or admin authority is embedded. The app deletes only the owner session cookie on entry and close; explicit Sign out invalidates the server session, otherwise it expires in 30 minutes. Server-side login remains mandatory. The public activation API stays separate. This is a transitional embedded panel, not a native Compose owner dashboard; visual integration and actual Android WebView form Origin/cookie behavior need on-device verification.
